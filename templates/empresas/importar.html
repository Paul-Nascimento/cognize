Como funciona

A planilha deve ter as colunas: ID Sistema, CNPJ, Regime Tributário, Inscrição ISS, Inscrição ICMS e Observações.

Empresas com ID já existente são atualizadas; as novas são criadas com status Pendente.

Depois, use o botão Processar fila na lista de empresas para puxar os dados oficiais da ReceitaWS respeitando o limite de 3 consultas/minuto.
